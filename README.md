# DRMD 6DOF — Оружейная Мастерская

![Workshop](https://img.shields.io/badge/SCK-Weapon%20Workshop-blue)
![Status](https://img.shields.io/badge/status-Production%20Ready-green)
![Garry's Mod](https://img.shields.io/badge/Garry's%20Mod-Addon-orange)

**DRMD 6DOF** — это расширенный аддон для Garry's Mod, добавляющий полнофункциональный боевой движок в режиме 6 степеней свободы. Эта версия включает **Оружейную Мастерскую** — встроенный редактор для проектирования, настройки и экспорта оружия в реальном времени.

---

## 🎯 Основные возможности

### Оружейная Мастерская
Полнофункциональный редактор с 4 интегрированными вкладками:

- **Статистика** — базовые параметры (имя, класс, категория, тип, скорострельность, урон, энергозатраты)
- **Снаряд** — физика и баллистика (модель, масса, гравитация, затухание, время жизни, наведение)
- **Осколки** — кассетные системы (количество, разброс, детонация, параметры фрагментов)
- **Наведение** — системы наведения (тепловое, целевое, луч, прогнозирование)

### Генерация кода
Автоматическое создание полноценного SWEP .lua файла:
- Экспорт в буфер обмена
- Сохранение в `DATA/drmd_weapons/generated/`
- Готовый к использованию код, вызывающий `D6_Wep.FireProjectile`

### Система пресетов
- **Сохранение / загрузка** конфигураций
- **Клонирование** готовых конфигов
- **Встроенные шаблоны** (Пушка, Ракета, Осколки, Ищущая ракета)
- **Сохранение всех состояний** (модели, боне-моды, параметры оружия, кластеры)

### Архитектура, управляемая схемой
Один универсальный рендер питается от описаний полей — легко расширяемо без изменения кода интерфейса.

---

## 🏗️ Архитектура

### Трёхслойная система

#### 1️⃣ Слой схем (`schema.lua`)
Определяет структуру полей для 4 категорий параметров оружия:

```lua
SCK_SCHEMA.weapon      -- Механика (имя, тип, урон, энергия и т.д.)
SCK_SCHEMA.projectile  -- Физика снаряда (модель, масса, время жизни)
SCK_SCHEMA.flak        -- Кассетные системы (осколки, детонация)
SCK_SCHEMA.guidance    -- Наведение (тепловое, целевое, прогнозирование)
```

#### 2️⃣ Реестр конфигураций (`config.lua`)
Система хранения и синхронизации:
- Хранение конфигов в памяти
- Сохранение на диск (glon-кодирование в `DATA/drmd_weapons/`)
- Синхронизация сервер ↔ клиенты через `net.Send`
- Поддержка расширений схемы

#### 3️⃣ Рендер интерфейса (`ui_schema.lua`)
Универсальный строитель панелей:

```lua
SCK_BuildSchemaPanel(panel, schema, data, onChange)
```

Автоматически создаёт нужные элементы управления:
- `int/float` → `DNumSlider`
- `string` → `DTextEntry`
- `bool` → `DCheckBoxLabel`
- `enum` → `DComboBox`

## 🎮 Использование

### Проектирование нового оружия

1. **Дайте себе SCK** → `give swep_construction_kit`
2. **Откройте меню** → ЛКМ или ПКМ
3. **Вкладка "Статистика"** → Установите имя, тип, скорострельность, урон
4. **Вкладка "Снаряд"** → Модель, масса, скорость, наведение
5. **Вкладка "Осколки"** (опционально) → Взрыв с разбросом фрагментов
6. **Вкладка "Наведение"** (опционально) → Параметры наведения
7. **Вкладка "Кластеры"** → Добавьте детали оружия (стволы, пусковые установки и т.д.)
8. **Кнопка "Копировать код SWEP"** → Вставьте в файл оружия
9. **Кнопка "Сохранить"** → Сохраните полную конфигурацию

### Миграция существующего оружия

Старое оружие с жёсткокодированными параметрами:
```lua
local ENERGY_COST = 20
local FIRE_RATE = 0.8
local DIRECT_DMG = 80
```

Сделайте его живо-настраиваемым:
```lua
local ENERGY_COST = D6_Wep.Cfg("weapon_d6_custom", "weapon", "EnergyCost", 20)
local FIRE_RATE = D6_Wep.Cfg("weapon_d6_custom", "weapon", "FireRate", 0.8)
local DIRECT_DMG = D6_Wep.Cfg("weapon_d6_custom", "weapon", "Damage", 80)
```

Или оставьте как есть — старые оружия продолжат работать без изменений.

## 🔌 Интеграция DRMD

### SCK полностью автономен
- Не требует DRMD для работы
- Генерирует валидные SWEP файлы
- Сохраняет и загружает пресеты независимо

### DRMD добавляет:

#### 1. Функция `D6_Wep.Cfg()` (`d6_wep_cfg.lua`)
```lua
function D6_Wep.Cfg(class, section, key, default)
    if not SCK_Config then return default end
    local cfg = SCK_Config.Get(class)
    if not cfg then return default end
    return cfg[section][key] or default
end
```

**Назначение:** Позволяет оружию читать конфигурацию из реестра вместо жёсткокодированных локальных переменных. Если SCK отсутствует, возвращает значение по умолчанию.

#### 2. Расширения схемы
```lua
SCK_Config.RegisterSchemaExtension("weapon", "Category", {
    "Anti-Fighter", "Anti-Capital", "Siege",
})
SCK_Config.RegisterSchemaExtension("weapon", "AmmoType", {
    "gravitic", "dark_energy",
})
```

Добавляет DRMD-специфичные категории и типы боеприпасов в редактор.

#### 3. Панель Мастерской в меню Q
`d6_weaponworkshop.lua` добавляет:
- Список сохранённых пресетов
- Встроенные архетипы оружия
- Батарейный экспорт

## 🔧 Генерация кода

### Что генерирует система

Полный, валидный SWEP файл:

```lua
-- Generated by DRMD Weapon Workshop (SCK)
AddCSLuaFile()

SWEP.PrintName = "Custom Weapon"
-- ... метаданные ...

local ENERGY_COST = 10
local FIRE_RATE = 0.5
-- ... константы из конфига ...

function SWEP:PrimaryAttack()
    if not D6_Energy.TryConsume(owner, "weapons", ENERGY_COST) then return end
    D6_Wep.FireProjectile({
        owner = owner,
        pos = pos,
        dir = dir,
        speed = PROJ_SPEED,
        model = "...",
        dmgClass = "kinetic",
        -- ... параметры из projectile ...
    })
end
```

### Возможности

✅ Автоматическое обнаружение типа оружия (снаряд vs хитскан)
✅ Интеграция с `D6_Wep.FireProjectile`
✅ Обработка попадания с урон + взрыв
✅ Цикл создания осколков (если включено)
✅ Блок WeaponClusters (если наличествует)
✅ Комментарий о пути миграции на `D6_Wep.Cfg()`

## 💾 Сохранение и пресеты

### Структура пресета
```lua
save_data = {
    -- Существующие поля SCK
    v_models, w_models, v_bonemods,
    ViewModel, CurWorldModel, ViewModelFOV,
    clusters,  -- Из вкладки "Кластеры"
    
    -- НОВОЕ: конфигурация оружия (все 4 раздела)
    weaponconfig = {
        weapon = {...},
        projectile = {...},
        flak = {...},
        guidance = {...}
    }
}
```

### Сохранение
- Гарантирует: `DATA/swep_construction_kit/<имя>.txt`
- Формат: glon-кодированная таблица Lua
- Загрузка одного пресета восстанавливает все 4 вкладки редактора

- [ ] Измените Урон слайдером → реестр обновляется в реальном времени

- [ ] Значение синхронизируется на сервер

### Генерация кода
- [ ] Клик "Копировать код SWEP" → код в буфере обмена
- [ ] Вставьте в файл → `luajit -bl` парсит без ошибок
- [ ] Спавните оружие → снаряд летит с настроенной скоростью/уроном

### Пресеты
- [ ] Сохраните → загрузите → полная конфигурация восстановлена
- [ ] Клонируйте → новое имя
- [ ] Примените шаблон (Пушка/Ракета/Осколки/Ищущая) → загрузилась конфигурация

### Независимость
- [ ] Удалите DRMD → SCK редактор работает, генерация работает, пресеты работают

### Без регрессии
- [ ] Существующее оружие стреляет без изменений (не читает реестр)

## 🎨 Дизайн-решения

### 1. Управляемая схемой архитектура
- Одна функция рендера питается от описаний полей
- Четыре вкладки отличаются только схемой
- Легко добавить новую вкладку: просто добавьте схему

### 2. Живой реестр + сохранение на диск
- Изменения применяются мгновенно
- Синхронизация между клиентами через net
- Старые оружия не трогаются (opt-in миграция)

### 3. Полная автономия SCK
- SCK работает без DRMD
- DRMD использует SCK как опциональный инструмент
- Однонаправленная зависимость: DRMD → SCK, SCK ↛ DRMD

### 4. Генерация кода, не только конфиг
- Полный, валидный Lua (не только константы)
- Вывод осведомлён о фреймворке `D6_Wep`
- Готов к использованию в игре

## 🤝 Участие

Система модульна и расширяема:

- **Добавить поле в схему?** Отредактируйте `schema.lua`, оно авто-отрендерится
- **Добавить тип элемента управления?** Добавьте case в `ui_schema.lua`
- **Добавить выбор DRMD?** Вызовите `SCK_Config.RegisterSchemaExtension()` из `d6_wep_cfg.lua`
- **Расширить генератор?** Добавьте логику в `BuildSWEPString()` в `generator.lua`

Весь код находится в пространстве имён `SCK_*` (публичный API) или file-local. Нет глобальных переменных.
