## Управление как в Descent

| Ось | Кнопка хотбара | Что делает |
|-----|----------------|------------|
| **Нос ↑↓** (pitch) | Нос вверх / вниз | Поворот вокруг поперечной оси корабля |
| **Бочки ←→** (roll) | Бочка влево / вправо | Крен вокруг продольной оси |
| **Рысканье ←→** (yaw) | Рысканье влево / вправо | Поворот вокруг «верха» корабля |
| Тяга вперёд | Прыжок или **Тяга** | Импульс вдоль носа |
| Скольжение ↑↓ | Скольжение вверх/вниз | Сдвиг вдоль локального UP |
| Стрейф | Стрейф ←→ | Сдвиг вбок |
| Рывок / Тормоз / Форсаж | отдельные кнопки | — |
| Выровнять | Выровнять крен | Level attitude |

**Удерживай** кнопку в хотбаре = непрерывно (как зажатая ось в Descent).  
Камера следует за носом (pitch/yaw). Roll виден на HUD (полоска R).

## На экране

- ActionBar: `SPD` · `P` (pitch) · `R` (roll) · активные оси `[НОС↑ БОЧКА→ …]`
- Подсказки: `!d6 hud` или Панель → «Показать подсказки HUD»
- Старт: title с раскладкой управления

## Установка

1. Активируй BP + RP **DRMD 6DOF (MCPE Master)**  
2. **Beta APIs = ВКЛ**  
3. `/function drmd/start` или зайди в мир  

Чат: `!d6 panel` · `!d6 hud` · `!d6 level` · `!d6 kit`
