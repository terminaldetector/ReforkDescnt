## Полёт бочкой — отдельный интерфейс

Кнопка **«Полёт бочкой»** в хотбаре (`drmd:ctrl_barrel`), пункт «Полёт бочкой…»
в главной панели, или `!d6 barrel`.

| Кнопка | Что делает |
|--------|------------|
| Бочка 360° влево / вправо | Скриптованный полный оборот вокруг продольной оси |
| Полубочка 180° | Переворот вверх ногами |
| Двойная бочка 720° | Два оборота подряд |
| Непрерывная бочка ← / → | Крутится, пока не нажмёшь «Стоп» |
| Стоп манёвр | Прервать |
| Скорость крена | медленно / норма / быстро (2.6 / 4.8 / 8.0 °/тик) |
| Выровнять крен | Обнулить бан |

Манёвр **не блокирует ручной крен**: удержание «Бочка ←/→» складывается с
манёвром, поэтому из бочки можно вырулить, не прерывая её.

Ход манёвра виден на HUD: `[БОЧКА 360° ████░░░░]`, у непрерывной — `[БОЧКА → ∞]`.

Быстрые команды: `!d6 roll360` · `!d6 roll180` · `!d6 rollcont` · `!d6 rollstop`

## Управление как в Descent

| Ось | Кнопка хотбара | Что делает |
|-----|----------------|------------|
| **Нос ↑↓** (pitch) | Нос вверх / вниз | Поворот вокруг поперечной оси корабля |
| **Бочки ←→** (roll) | Бочка влево / вправо | Крен вокруг продольной оси |
| **Рысканье ←→** (yaw) | Рысканье влево / вправо | Поворот вокруг «верха» корабля |
| Тяга вперёд | Прыжок или **Тяга** | Импульс вдоль носа |
| Скольжение ↑↓ | Скольжение вверх/вниз | Сдвиг вдоль локального UP |
| Стрейф | Стрейф ←→ | Сдвиг вбок |
| Рывок / Тормоз / Форсаж | отдельные кнопки | — |
| Выровнять | Выровнять крен | Level attitude |

**Удерживай** кнопку в хотбаре = непрерывно (как зажатая ось в Descent).

## Выравнивание с ПК-версией

| Что | Статус |
|-----|--------|
| Матрица крена | **Идентична ПК.** Опорный кадр берётся из `levelRightOf/levelUpOf` — из yaw, а не через `forward × worldUp`. Расхождение с Java-реализацией — 2.8e-14° |
| Обзор через полюс | Нет снэпа на ±174°, который был при `\|forward.y\| > 0.95` |
| Бочка | Не ограничена — крутится в одну сторону бесконечно |
| Демпферы (Flight Assist) | Есть, `!d6 damp` — как `F` на ПК |
| HUD | `6DOF · ТЯГА% · ДЕМПФ · SPD · P · R · ALT · уровень` — те же величины, что в кокпите ПК |
| Уровни мира | Метки те же (`NETHER / ABYSS / INDUSTRIAL / SURFACE / SKY / ORBITAL / END`) |

**Чего на Bedrock нет и не будет:** камера не кренится. Скриптовый API даёт
только yaw/pitch, поворота вокруг оси взгляда нет — поэтому крен здесь читается
по приборам (`R` + полоса), а не по горизонту. На ПК крен идёт в матрицу вида.

**Высота мира:** Bedrock не даёт переопределить `dimension_type`, поэтому мир
остаётся −64…320. Полосы `NETHER / ABYSS / ORBITAL / END` подписаны теми же
порогами, что на ПК, но физически недостижимы — на MCPE доступны
`INDUSTRIAL / SURFACE / SKY`.

## На экране

- ActionBar: режим · тяга % · демпферы · `SPD` · `P` (pitch) · `R` (roll) · `ALT` · уровень
- Во время манёвра хвост строки занимает прогресс бочки
- Подсказки: `!d6 hud` или Панель → «Показать подсказки HUD»

## Установка

1. Активируй BP + RP **DRMD 6DOF (MCPE Master)**
2. **Beta APIs = ВКЛ**
3. `/function drmd/start` или зайди в мир

Чат: `!d6 panel` · `!d6 barrel` · `!d6 hud` · `!d6 level` · `!d6 damp` · `!d6 kit`
