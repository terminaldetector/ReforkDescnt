## 📖 О DRMD 6DOF

**DRMD 6DOF** (Descent-Inspired Resource Management Dynamics) — это инновационный боевой аддон для Garry's Mod, вдохновлённый классической серией Descent. Система обеспечивает полную свободу движения в трёхмерном пространстве с полноценной боевой механикой.

### Компоненты системы

#### 🚀 **Ядро полёта и управления**
- **6DOF контроллер полёта** — полная свобода движения в 3D (pitch, yaw, roll)
- **Система инерции** — реалистичная физика ускорения и торможения
- **Динамика вращения** — правильные угловые скорости и момент
- **Избежание столкновений** — адаптивный воздушный конвейер

#### ⚡ **Энергетическая система**
- **Энергетический реестр** — управление ресурсами между подсистемами
- **Распределение питания** — пресеты (Сбалансированный, Атака, Перехват, Осада)
- **Восстановление** — скорость регенерации зависит от выбранного пресета
- **Потребление оружия** — каждое оружие имеет энергозатраты

#### 🛡️ **Система щитов**
- **Многоуровневая защита** — корпус + щиты
- **Поглощение повреждений** — распределение по типам урона (кинетический, энергия, взрыв)
- **Восстановление щитов** — пассивная регенерация
- **Эффекты защиты** — визуальная обратная связь при попадании

#### 🎯 **Боевая механика**
- **Система оружия** — модульная архитектура (20+ встроенных типов)
- **Типы урона** — кинетический, энергия, взрыв, экзотический
- **Наведение** — различные системы наведения для специализированного оружия
- **Проектили и лучи** — полная поддержка и хитскана, и физических снарядов

#### 🤖 **Интеллект противников**
- **Враждебные НПЦ** — разные классы (Истребители, Перехватчики, Артиллерия, Поддержка)
- **AI навигация** — интеграция сNav-сеткой Garry's Mod
- **Тактическое поведение** — групповые манёвры и расчётные атаки
- **Динамичный баланс** — враги адаптируются к действиям игрока

#### 🎨 **Система визуализации**
- **Кластеры оружия** — модульное расположение деталей (Center, Upper, SideLeft, SideRight, Lower)
- **SWEP Construction Kit** — визуальный редактор моделей оружия
- **HUD система** — информативный дисплей энергии, боеприпасов, статуса

#### 🔧 **Оружейная Мастерская** (эта версия)
- **4 встроенных редактора** — Статистика, Снаряд, Осколки, Наведение

## 🎯 Основные возможности

Оружейная Мастерская обеспечивает полный цикл разработки оружия для DRMD:

### Оружейная Мастерская
Полнофункциональный редактор с 4 интегрированными вкладками:

- **Статистика** — базовые параметры (имя, класс, категория, тип, скорострельность, урон, энергозатраты)
- **Снаряд** — физика и баллистика (модель, масса, гравитация, затухание, время жизни, наведение)
- **Осколки** — кассетные системы (количество, разброс, детонация, параметры фрагментов)
- **Наведение** — системы наведения (тепловое, целевое, луч, прогнозирование)

### Генерация кода
Автоматическое создание полноценного SWEP .lua файла:
- Экспорт в буфер обмена
- Сохранение в `DATA/drmd_weapons/generated/`
- Готовый к использованию код, вызывающий `D6_Wep.FireProjectile`

### Система пресетов
- **Сохранение / загрузка** конфигураций
- **Клонирование** готовых конфигов
- **Встроенные шаблоны** (Пушка, Ракета, Осколки, Ищущая ракета)
- **Сохранение всех состояний** (модели, боне-моды, параметры оружия, кластеры)

### Архитектура, управляемая схемой
Один универсальный рендер питается от описаний полей — легко расширяемо без изменения кода интерфейса.

## 🏗️ Архитектура

### Трёхслойная система

#### 1️⃣ Слой схем (`schema.lua`)
Определяет структуру полей для 4 категорий параметров оружия:

```lua
SCK_SCHEMA.weapon      -- Механика (имя, тип, урон, энергия и т.д.)
SCK_SCHEMA.projectile  -- Физика снаряда (модель, масса, время жизни)
SCK_SCHEMA.flak        -- Кассетные системы (осколки, детонация)
SCK_SCHEMA.guidance    -- Наведение (тепловое, целевое, прогнозирование)
```

#### 2️⃣ Реестр конфигураций (`config.lua`)
Система хранения и синхронизации:
- Хранение конфигов в памяти
- Сохранение на диск (glon-кодирование в `DATA/drmd_weapons/`)
- Синхронизация сервер ↔ клиенты через `net.Send`
- Поддержка расширений схемы

#### 3️⃣ Рендер интерфейса (`ui_schema.lua`)
Универсальный строитель панелей:

```lua
SCK_BuildSchemaPanel(panel, schema, data, onChange)
```

Автоматически создаёт нужные элементы управления:
- `int/float` → `DNumSlider`
- `string` → `DTextEntry`
- `bool` → `DCheckBoxLabel`
- `enum` → `DComboBox`

## 🎮 Игровой цикл DRMD + Мастерская

### Полный процесс разработки оружия

1. **Планирование** — Определите роль оружия в арсенале DRMD (антиперехват, тяжёлое, поддержка)
2. **Проектирование в Мастерской** — Используйте 4 редактора для настройки параметров
3. **Проверка энергобюджета** — Убедитесь, что энергозатраты уравновешены с восстановлением
4. **Генерация кода** — Экспортируйте SWEP Lua
5. **Тестирование в игре** — Спавните оружие, проверьте поведение против врагов
6. **Live-tuning** — Отредактируйте параметры в Мастерской, измените в реальном времени
7. **Сохранение пресета** — Зафиксируйте финальную конфигурацию
8. **Интеграция** — Добавьте оружие в D6_COMBAT или назначьте врагам

### Пример: проектирование ракеты класса "Перехват"

**Требование:** быстрая наводящаяся ракета для боёв с истребителями

**Шаги:**
1. **Статистика:**
   - PrintName: "Ищущая ракета"
   - Category: "Anti-Fighter"
   - FireRate: 3.5 сек (дорогая, редкая)
   - Damage: 60
   - EnergyCost: 28
   - SplashRadius: 160

2. **Снаряд:**
   - Model: "models/weapons/w_missile.mdl"
   - InitialVelocity: 1400 u/s
   - Lifetime: 15 сек
   - Homing: true
   - TurnRate: 4.5

3. **Наведение:**
   - GuidanceType: "target"
   - TargetSeeking: true
   - LockTime: 0.5 сек
   - TrackingCone: 60°

4. **Кластеры:**
   - Center: пусковая установка
   - Lower: стабилизаторы

5. **Генерация** → "Copy SWEP Lua"

6. **Тестирование** → спавните `weapon_d6_custom` против врагов-истребителей

7. **Балансировка** → измените TurnRate/LockTime в Мастерской, видите результат в реальном времени

### Пример: миграция старого оружия на live-tuning

**Было:**
```lua
-- weapon_d6_laser.lua
local ENERGY_COST = 22
local FIRE_RATE = 0.40
local DIRECT_DMG = 40
```

**Стало:**
```lua
-- weapon_d6_laser.lua
local ENERGY_COST = D6_Wep.Cfg("weapon_d6_laser", "weapon", "EnergyCost", 22)
local FIRE_RATE = D6_Wep.Cfg("weapon_d6_laser", "weapon", "FireRate", 0.40)
local DIRECT_DMG = D6_Wep.Cfg("weapon_d6_laser", "weapon", "Damage", 40)
```

**Теперь:** можно настраивать лазер в Мастерской без перезагрузки игры.

```lua
local ENERGY_COST = 20
```

```lua
local ENERGY_COST = D6_Wep.Cfg("weapon_d6_custom", "weapon", "EnergyCost", 20)
```

## 🔌 Интеграция с DRMD Engine

### Как Мастерская подключается к DRMD

**Оружейная Мастерская** разработана как **дополнение к DRMD Engine**, но остаётся полностью независимой:

- **Генерирует оружие для DRMD** — создаёт SWEP файлы, вызывающие `D6_Wep.FireProjectile()`
- **Использует D6_DAMAGE taxonomy** — интегрируется с системой типов урона DRMD
- **Поддерживает энергосистему** — оружие потребляет энергию через `D6_Energy.TryConsume()`
- **Совместимо с щитами** — урон проходит через `D6_Wep.DirectDamage()` и `D6_Wep.SplashDamage()`

### SCK полностью автономен
- **Работает без DRMD** — генерирует валидные SWEP файлы
- **Независимое сохранение** — пресеты хранятся локально, не требуют DRMD
- **Универсальный редактор** — можно использовать для любых SWEPs, не только DRMD оружия

### DRMD добавляет:

#### 1. Функция `D6_Wep.Cfg()` (`d6_wep_cfg.lua`)
```lua
function D6_Wep.Cfg(class, section, key, default)
    if not SCK_Config then return default end
    local cfg = SCK_Config.Get(class)
    if not cfg then return default end
    return cfg[section][key] or default
end
```

**Назначение:** Позволяет оружию читать конфигурацию из реестра вместо жёсткокодированных локальных переменных. Если SCK отсутствует, возвращает значение по умолчанию.

#### 2. Расширения схемы
```lua
SCK_Config.RegisterSchemaExtension("weapon", "Category", {
    "Anti-Fighter", "Anti-Capital", "Siege",
})
SCK_Config.RegisterSchemaExtension("weapon", "AmmoType", {
    "gravitic", "dark_energy",
})
```

Добавляет DRMD-специфичные категории и типы боеприпасов в редактор.

#### 3. Взаимодействие с боевой системой DRMD

Сгенерированное оружие автоматически интегрируется с:
- **D6_Wep.FireProjectile()** — физический снаряд с наследованием скорости
- **D6_Wep.DirectDamage()** — прямой урон с отталкиванием
- **D6_Wep.SplashDamage()** — AoE взрывной урон
- **D6_Wep.ApplyRecoil()** — отдача оружия
- **D6_Energy.TryConsume()** — потребление энергии
- **D6_DAMAGE классы** — кинетический, энергия, взрыв, экзотический

#### 4. Панель Мастерской в меню Q
`d6_weaponworkshop.lua` добавляет:
- Список сохранённых пресетов
- Встроенные архетипы оружия
- Батарейный экспорт

## 🔧 Генерация кода

### Что генерирует система

Полный, валидный SWEP файл:

```lua
-- Generated by DRMD Weapon Workshop (SCK)
AddCSLuaFile()

SWEP.PrintName = "Custom Weapon"
-- ... метаданные ...

local ENERGY_COST = 10
local FIRE_RATE = 0.5
-- ... константы из конфига ...

function SWEP:PrimaryAttack()
    if not D6_Energy.TryConsume(owner, "weapons", ENERGY_COST) then return end
    D6_Wep.FireProjectile({
        owner = owner,
        pos = pos,
        dir = dir,
        speed = PROJ_SPEED,
        model = "...",
        dmgClass = "kinetic",
        -- ... параметры из projectile ...
    })
end
```

### Возможности

✅ Автоматическое обнаружение типа оружия (снаряд vs хитскан)
✅ Интеграция с `D6_Wep.FireProjectile`
✅ Обработка попадания с урон + взрыв
✅ Цикл создания осколков (если включено)
✅ Блок WeaponClusters (если наличествует)
✅ Комментарий о пути миграции на `D6_Wep.Cfg()`

## 🎨 Дизайн-решения

### 1. Управляемая схемой архитектура
- Одна функция рендера питается от описаний полей
- Четыре вкладки отличаются только схемой
- Легко добавить новую вкладку: просто добавьте схему

### 2. Живой реестр + сохранение на диск
- Изменения применяются мгновенно
- Синхронизация между клиентами через net
- Старые оружия не трогаются (opt-in миграция)

### 3. Полная автономия SCK
- SCK работает без DRMD
- DRMD использует SCK как опциональный инструмент
- Однонаправленная зависимость: DRMD → SCK, SCK ↛ DRMD

### 4. Генерация кода, не только конфиг
- Полный, валидный Lua (не только константы)
- Вывод осведомлён о фреймворке `D6_Wep`
- Готов к использованию в игре

## 🤝 Участие

Система модульна и расширяема:

- **Добавить поле в схему?** Отредактируйте `schema.lua`, оно авто-отрендерится
- **Добавить тип элемента управления?** Добавьте case в `ui_schema.lua`
- **Добавить выбор DRMD?** Вызовите `SCK_Config.RegisterSchemaExtension()` из `d6_wep_cfg.lua`
- **Расширить генератор?** Добавьте логику в `BuildSWEPString()` в `generator.lua`

Весь код находится в пространстве имён `SCK_*` (публичный API) или file-local. Нет глобальных переменных.
