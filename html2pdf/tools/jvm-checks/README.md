# jvm-checks — проверки конвейера без телефона

Небольшой JVM-проект, который **компилирует настоящие исходники приложения**
(`android/lj2pdf/app/src/main/java`, а не их копии) и прогоняет по ним тесты.
Так проверяется именно то, что попадёт в APK, и проверки не расходятся с кодом.

```bash
cd html2pdf/tools/jvm-checks
gradle test          # или ./gradlew test, если добавите wrapper
```

## Что проверяется

| Файл | Что покрывает |
|------|---------------|
| `FacebookTest` | распознавание facebook-ссылок; стабильный id поста (`story.php` / `permalink.php` / `/posts/<id>` → один и тот же файл); нормализация в mbasic и отбрасывание трекинга; URL ленты для профиля / `profile.php?id=` / группы / прямого поста; отдельное имя проекта на каждую цель; разворачивание `l.php?u=`; распознавание страницы входа; обход ленты по «показать ещё» с дедупликацией; лимит; остановка обновления на уже скачанном посте; отмена; заголовок главы |
| `BrowserSessionTest` | сессию несут **только** запросы к Facebook (чужой блог качается анонимно); `c_user` как признак входа; cookie + `User-Agent` в заголовках; выход стирает сессию |
| `PipelineTest` | **выгрузка содержимого**: пост Facebook и пост LiveJournal → HTML-база (текст на месте, реклама и служебные блоки вырезаны, картинки скачаны и переписаны на локальные пути); протухшая сессия сообщается, а не «найдено 0»; **EPUB**: корректный zip (`mimetype` первым и STORED), `container.xml`, `content.opf`, `nav.xhtml`, `toc.ncx`, главы с текстом и вшитыми картинками; **RAG**: JSONL с нужными полями, размер и перекрытие чанков, ничего не теряется, движок `mempalace`; **PDF-книга**: слияние глав, число страниц, кириллические закладки в outline, кликабельное оглавление, текст читается обратно |

## Чего здесь нет

`PdfRenderer2` (рендер поста в PDF через `StaticLayout`/`PdfDocument`) и окно
входа `FacebookLoginActivity` завязаны на настоящий Android и проверяются только
на устройстве/эмуляторе. Всё, что до и после них, покрыто здесь.

## Как это устроено

`src/stubs/kotlin` подменяет ровно тот минимум платформы, который нужен, чтобы
настоящие файлы скомпилировались на JVM:

* `android.net.Uri` — разбор/сборка URL с той же семантикой;
* `android.content.Context` — приватная папка и `assets` (оттуда берётся
  настоящий кириллический шрифт для оглавления PDF);
* `android.webkit.CookieManager` / `WebSettings` — cookie-хранилище в памяти;
* `android.graphics.*` — заглушки уменьшения картинок;
* `com.tom_roush.pdfbox.*` → `org.apache.pdfbox.*` — у pdfbox-android тот же API,
  только другой пакет, поэтому `BookBuilder` и `RagExporter` работают как есть;
* `ConvertBus`, `Http`, `Logx`, `Translator` — шина в память и HTTP, отдающий
  подготовленные страницы вместо сети.

Список исключённых файлов и причина — в `build.gradle.kts`.
