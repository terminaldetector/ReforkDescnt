# N — Гибридный рендер / Hybrid Renderer: настройка и default ON

**Явное требование автора:** гибридный рендер должен быть доступен в настройках и **включён по умолчанию**. **P1**. Это отдельная ветка от зеркал, порталов и Expanded Physics. Не путать гибридный рендер с одной галочкой `Voxel Horizon`.

## Задачи
1. Аудит фактических рендер-подсистем: near vanilla chunks, high-altitude/horizon, LLOD/DH, sky layer, special blocks, 6DoF camera, NoCubes-like drill meshes, particles, mirrors, portal rendering. Задокументировать, что реально входит в профиль `HYBRID`, без маркетингового термина.
2. Ввести или восстановить отдельный переключатель **«Гибридный рендер»**, сохраняемый в клиентской конфигурации; отсутствие сохранённого ключа и свежая установка → `HYBRID=true`. При явном `false` уважать выбор после рестарта. Неправильные legacy значения мигрировать безопасно.
3. HYBRID включает композицию near world + дальнего LOD + применимые сглаженные геометрические/эффектные passes, только **если они действительно готовы**, без двух экземпляров одного мира или overlapping depth. Не форсировать поломанный высотный рендер без исправления UG-003; режим может сообщить `partial/degraded` при unsupported capability.
4. Дополнительные переключатели подрежимов (`Voxel Horizon`, `DH`, NoCubes-like, shadows, portal view/mirrors) остаются независимыми. Главный профиль определяет pipeline/предустановку, но не ломает индивидуальные пользовательские флаги без явного действия.
5. Pipeline должен быть изолирован от серверной физики: `HYBRID OFF` меняет изображение, но не material/block data, physics profile, projectile hits или логику строительства.
6. На первом запуске/старом конфиге проверить `config` фактически загружается **до** регистрации renderer hooks; toggling в UI перерегистрирует или обновляет корректные state, FBO, buffers, resource disposal; не оставляет ghost meshes. Для опасной смены, требующей reload, выводить явное сообщение.
7. Проверить сочетания: 6DoF roll 0/90/180, Y=Surface/Orbit/Oblivion, высокая скорость, near/far seamless, NoCubes drill chunks, зеркала и порталы только при их включении. Сравнить FPS/GPU/VRAM, rebuild cost и screenshots.

## Исходное состояние, требующее сверки
- В читаемой ветке `client/config/DescentConfig.java` поля `hybridRender` нет, а `client/screen/DescentSettingsScreen.java` предлагает лишь subset опций и отличается от меню в видеозаписи. Следовательно, **не считать найденную GitHub ветку той же сборкой, что в видео**. Codex должен сначала подтвердить актуальную ревизию.

## Приёмка
- Fresh config / отсутствующий ключ: **Гибридный рендер: Вкл**. Explicit OFF сохраняется, включение после OFF сохраняется. Главный экран и настройка показывают действительное состояние.
- Включённый профиль реально задействует согласованную рендер-архитектуру, а не декоративную галочку. Нет исчезающих дальних поверхностей, двойной геометрии и неожиданных падений при unload/resize.
