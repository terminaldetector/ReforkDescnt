# J — Очистка наследия предыдущих агентов / Dead & legacy code

**Проблема пользователя:** мусорные и неиспользуемые части прошлых итераций, дубли, устаревшие ассеты и код. **P2** по умолчанию, P1 если влияют на регистрацию/сборку/время загрузки. Это **аудит использования**, не команда удалить всё старое.

## Правила
1. Зафиксировать commit, запущенный JAR (если известен), активный main sourceSet и asset path. Отличить живые классы, тестовые заглушки, неиспользуемые ассеты, архивные файлы и экспериментальные ветки.
2. Построить граф ссылок: Java import/instantiation; Fabric entrypoints/mixins; регистрация items, blocks, entities, renderers, event handlers, datapack recipes, tags, loot, models/textures, lang keys, tests/CI. Reflection, registry names и динамические loaders проверять, а не считать нулём использования.
3. Вывести отчёт `path | origin/назначение | references | runtime registration | status | removal risk | proposed action`.
4. Этап 1: переименовать/изолировать экспериментальные части или подготовить PR удалений. Этап 2: удалять только после доказательства отсутствия ссылок, совместимости сериализованных ID и успешного повторного rendercheck/gameplay.
5. Для ID, встречающихся в сохранённых мирах, обеспечить совместимость или миграцию. Для item ID и block ID не делать тихую замену; не удалять работающие механики 6DoF, swarm, gravity, weapon systems.
6. Не трогать доступ к сети/online системы вне этой задачи. Не возвращать вычеркнутую 3D-модель Pyro.

## Кандидаты на разбор (не на автоматическое удаление)
- Старые ZIP/бинарные дистрибутивы в корне; убедиться, что не нужны CI/release-процессу.
- Разрозненные версии однотипных моделей оружия и procedural `WeaponViewRenderer`.
- Неиспользуемые заготовки моделей, client debug renderer, старые registry aliases, устаревшие комментарии/технические документации.

## Приёмка
- Список что оставлено / что безопасно удалено / что требует решения автора.
- Компиляция, тесты, asset validation, старт клиента и мира, entity serialization/recipes, 6DoF, оружие, порталы, зеркала, физика. Минимальные раздельные изменения с обратимыми коммитами.
