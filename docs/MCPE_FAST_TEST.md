# MCPE Fast Test Edition

Статус: **спека / полигон**, не включено в Fabric jar.

## Цель

Быстрый touch-friendly прототип для проверки ощущений Phase 3 без тяжёлого Java-стека.

## Scope (in)

- 6DoF flight feel (упрощённая инерция)
- **MCPE Master** packaging: `.mcaddon` + `com.mojang` ZIP
- Touch control buttons + Control Panel (RU)
- `/function drmd/start|kit|help` fallback
- Construction / Gravity Torch
- Mini HUD (speed / roll / mode)

## Scope (out)

- Voxel LLOD
- Megastructures / MacroWorld
- Full weapon workshop
- Havok-complete gravy
- Industrial worldgen 2.0

## Relation to Fabric

Fabric = production Descent universe.  
MCPE Fast Test = UX sandbox. Успешные механики переносятся обратно в Java.
