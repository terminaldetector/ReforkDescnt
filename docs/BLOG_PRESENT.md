# DRMD 6DOF — презент-лог для блога

*Что это вообще такое, откуда взялось и зачем портуется в Minecraft.*

---

## Коротко

**DRMD 6DOF** — это не «мод на полёт». Это попытка превратить Minecraft в **трёхмерную воксельную вселенную в духе Descent**: ты летаешь по объёму, стреляешь дронов, строишь станции без «пола вниз», и мир вокруг тебя устроен как сеть пещер, реакторов и небесных мегаструктур — без загрузочных экранов между слоями.

Изначально проект жил как аддон для **Garry's Mod** (Descent-inspired 6DoF combat). Сейчас это **готовый Fabric-мод для Minecraft 1.21.1**: survival + creative, стоковая генерация мира, Pyro GX, оружейная мастерская.

---

## Откуда идея

В Descent (и в GMod-аддоне) камера и корабль имеют **шесть степеней свободы**: вперёд/назад, вверх/вниз, влево/вправо + крен/тангаж/рысканье. Нет привилегированного «низа». Пол — это любая грань, на которую ты ориентировался.

Minecraft по умолчанию — игра про поверхность: дом → шахта → Нижний мир → End. DRMD ломает эту лестницу. Вместо неё — **единый вертикальный континуум**:

| Слой | Смысл |
|------|--------|
| Глубина | Реакторные комплексы, индустриальные биомы |
| Поверхность | Классический Overworld, но уже с 6DoF |
| Небо | Архипелаги, арки, кольца, летающие материки |
| Орбита / End-space | Мегаструктуры, End-архипелаг, арена реактора |

Игрок пересекает всё это **непрерывным полётом**.

## Что уже есть в моде

### Бой и полёт
- Инерционный 6DoF (spool, drag, dash, flight assist, крюк)
- Энергия + пресеты, щиты
- ~27 оружий Descent/Doom-стиля
- Weapon Workshop + кластеры стволов

### Мир
- **6D Soil** — саженцы/рост на всех шести гранях (идея со сфер-ферм и мини-планет)
- Industrial Underground как стоковая генерация
- World Generation 2.0: разломы, каньоны, арки, кольца, материки, спирали, перевёрнутые острова
- Mega creatures как элементы ландшафта (червь, рой, keeper)
- Дальний вид — через Distant Horizons (soft-dep)

### Транспорт и враги
- **Pyro GX** — крафт в survival, быстрый деплой в creative
- 10 ролей дронов с 6DoF-attitude (yaw/pitch/roll по скорости)

### Интерфейс (концепт → мод)
HUD в духе кабины Descent: зелёный тактический оверлей — режим полёта, thrust, dampeners, gravity, скорость, координаты, 3D-радар, target lock, список оружия, щит/броня, боевой лог. Vanilla hotbar остаётся — это всё ещё Minecraft.

## Почему Minecraft, а не только GMod

В GMod физика (в т.ч. **Havok**) и prop-модели дают гравипушку и сложные стволы почти «из коробки». Minecraft проще — и это плюс для интерфейса и массового плеера:

- воксельный мир уже есть;
- survival-прогрессия понятна;
- можно сделать чистый кабинный HUD без борьбы с Source UI;
- модели стволов и кораблей можно держать procedural / Blockbench без тяжёлого пайплайна props.

Но гравипушка из GMod **требует** отдельного слоя физики для захватываемых объектов — это следующий большой кусок (см. `docs/ROADMAP.md`).

## Как потрогать

```bash
./gradlew build
# jar → mods/ + Fabric 1.21.1 + Fabric API
```

Зашёл в мир → 6DoF уже часть сессии. Скрафтил **Pyro GX** или взял из креатив-вкладки. Полетел к арке на горизонте.

Репозиторий: [terminaldetector/ReforkDescnt](https://github.com/terminaldetector/ReforkDescnt)
