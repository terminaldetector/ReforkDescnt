# Совместимость и откат Ungravity

Кубический мир зависит от схемы установленного Better Cubic Chunks. Для отката сначала сохраните закрытую папку мира вместе с `level.dat`, `region`, данными кубов, `entities`, `poi`, `data`, `datapacks` и конфигурацией экземпляра. Проверьте запуск на отдельной копии. Для возврата к Vanilla нужен Vanilla-мир или его резервная копия, сделанная до перехода на кубический пресет. Смена файла мода сама по себе не преобразует сохранение.

| Сбой или граница | Действие и подтверждение |
| --- | --- |
| Sodium 0.8.13 на контексте GL 3.2 / GLSL 150 завершает загрузку ошибкой `GLSL 3.30 is not supported` | Уберите Sodium из отдельного экземпляра, оставив тот же кубический backend и мир. Эта комбинация проверена в семи сценах зеркал и порталов на историческом стенде 1.1.19. Для Sodium требуется доступный контекст GL 3.3 / GLSL 330. [Логи и SHA](CUBIC_UPSTREAM_COMPATIBILITY_2026-11-19.md) |
| BCC 0.1.1 объявляет Loom 1.17.21, а встроенная Gradle-проверка Loom 1.10.5 отказывается перемапировать его как dev dependency | Для проверки используйте готовый неизменённый BCC с Fabric Loader 0.19.5 или новее и Java 21. Исторический gate запускает Knot с upstream JAR напрямую. Сверяйте SHA файла BCC и выбранную сборку мода перед запуском. [Логи и SHA](CUBIC_UPSTREAM_COMPATIBILITY_2026-11-19.md) |
| PS1-кадр с неверной композицией при работоспособном клиенте | В копии профиля переключите стиль на `HYBRID_NATIVE`. Он оставляет размер окна и интерфейс нативными и только меняет режим представления мира. Для диагностики сравните тот же маршрут, seed и угол камеры, сохранив оригинальный профиль. [Точная исходная проверка](MULTI_AGENT_INTEGRATION_11513CD_2026-11-17.md) |
| `save-all flush` внутри активного серверного callback однажды застопорил очередь загрузки BCC | Завершите активные проверки и дождитесь отсутствия операций размещения/переподключения, затем выполните сохранение через консоль и штатно остановите сервер. Рабочий сценарий подтверждён на том же историческом стенде командой из консоли. Архивируйте копию после выхода процесса. [История остановки](CUBIC_UPSTREAM_COMPATIBILITY_2026-11-19.md) |
| Better Distant Horizons, обычный Distant Horizons, сторонний NoCubes, Intel HD 4400 и импорт новых миров в старые версии | Для этих комбинаций отсутствует проверенный путь. Возврат выполняется к последней проверенной связке модов и к её собственному сохранению. [Границы upstream](CUBIC_UPSTREAM_COMPATIBILITY_2026-11-19.md) |

Сохранённая точка для воспроизведения Graphic G0 находится в `checkpoints/world-access-1.1.19`. Источник `0f76a0789fe8cb62ff98c3e08d6232f222d72cb8`, JAR `drmd-6dof-1.1.19-world.1-fabric-1.21.1.jar`, SHA-256 `3df5cfcbd41c03af0df44c28e2f11fd18f9754c0571ca7895bea0e4d38319298`. `RESTORE.md` и `SHA256SUMS` лежат рядом. Это диагностический откат для его собственного тестового сохранения.

```bash
cd /workspace/ungravity-v5/checkpoints/world-access-1.1.19
sha256sum -c SHA256SUMS
cd /workspace/ungravity-v5/ufo-body-physics
python3 scripts/v8/verify_cubic_compatibility.py \
  --checkpoints /workspace/ungravity-v5/checkpoints \
  --output /tmp/cubic-compatibility.json
```
