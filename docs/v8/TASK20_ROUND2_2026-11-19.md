## Решения реализации

- Кватернион хранится один раз и используется полётом и локальными координатами гравитации. Прежний сетевой формат ориентации сохранён. Штатный выход из 6DoF проверяет реальные занятые объёмы и ищет запасное место в доступных кубах.
- Повреждение и восстановление carved-блоков, тепловой бур, буровые и огонь читают фактическую загруженную геометрию. Переходы между натуральным и инженерным материалом используют общий классификатор. Сетка сохраняет криволинейные границы отверстий.
- /ungravitylab x y z размещает комнату и спуск к ней с запада. Координата задаёт уровень ног внутри комнаты. Нужен подключённый Creative-оператор с правом уровня 2, загруженный объём и разрешение менять клетки. Транзакция сохраняет обычные уведомления мира. Для существующего MINERS-вестника лаборатория затем связывается через /ungravitymission bind drmd:lab_infiltration <herald> <anchor>. Привязка не начисляет прогресс или репутацию.
- Саботаж реактора использует ближайшую реальную цель по тому же лучу, что локальные взаимодействия с BlockBody. Закрытый или защищённый реактор остаётся цел. При успешном саботаже действуют штатное отключение и сохраняемый отсчёт эвакуации.
- Зеркало и портал используют общую временную текстуру с восстановлением внешней цели рендера. Статус «рисуется» выставляется после фактической композиции апертуры. Реальный клиент проверил отдельные области отражения и портала в одном кадре. [Кадр](EVIDENCE/round2-20261119/mirror-and-portal.png).

## Воспроизведение

Команды выполняются на Java 21 из чистой копии нужной ревизии. Для GameTest используется изолированный свежий игровой каталог. Список классов и фильтры модульных тестов вложены рядом с серверными журналами. Если зависимости уже сохранены, возможен офлайн-запуск.

~~~bash
source_sha=ec696a32132c595aa29095211416abb3ba22acdf
git diff 9b97fe78 "$source_sha" -- src
proof=$(mktemp -d)
export JAVA_TOOL_OPTIONS="-Ddrmd.test.u07ProofDir=$proof"
unit_args=()
while IFS= read -r test_class; do
  unit_args+=(--tests "*$test_class")
done < docs/v8/EVIDENCE/round2-20261119/units.txt
./gradlew --offline --no-daemon -I scripts/v8/focused_gametest.init.gradle \
  "-PdrmdGameTests=$(cat docs/v8/EVIDENCE/round2-20261119/selector.txt)" \
  test "${unit_args[@]}" runGametest remapJar remapCubiccheckJar
~~~

Реальный клиент запускал поставляемый ремапнутый JAR с отдельным наблюдателем и точными версиями Fabric, BCC и Sodium. Для сцены зеркал используется свой BCC-тестовый мир и параметр JVM -Ddrmd.gate.mirrors=true. В архиве сохранены входные SHA, журналы и кадры. [Нативный архив](EVIDENCE/round2-20261119/native-dual-surface.zip).
