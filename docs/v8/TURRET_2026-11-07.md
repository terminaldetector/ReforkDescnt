## Gameplay and physical ownership

Craft `drmd:ship_turret_kit` from three iron blocks, one ship laser and one ship rocket. Hold it and right-click the real UFO console. Survival consumes exactly one kit; blocked geometry and duplicate installation preserve the kit. It is optional, not silently created on every UFO. The existing hull LMB/RMB weapon banks remain separate. The kit has a vanilla-texture item model, recipe and ru/en names/tooltips.

The child grid contains a three-block iron base, laser `(0,1,0)` and rocket `(0,2,0)`. The parent roof anchor is `(0,3,0)` with point `(.5,4,.5)`; the child base point is `(.5,0,.5)`. The bearing uses the existing local-X MOTOR with its frame rotated onto local Y. Its commanded yaw speed is bounded to 0.6 rad/s and torque to 40. No independent physics engine or RigidBody per block is introduced.

Rotated construction initializes orientation, COM and the complete inherited velocity field before entity spawn/tracking. Fire uses the actual child quaternion, muzzle point and `v + omega × radius`. Laser/rocket recoil impulses are 24/160 at those muzzles. A passive velocity solve transfers recoil through loaded existing joints without integrating poses, replaying forces or granting a second motor allowance. Root and child total linear plus world angular momentum are checked around the real fire call.

Motor C2S snapshots reject stale epoch, replay, invalid/nonfinite input and more than four updates per tick. A missing refresh expires after four ticks. B is Fire mask bit 4. Unowned carriers explicitly retire stored motor targets; saved joint speed is not a persisted pilot lease. Braking changes the motor target, never the body's pose or velocity directly. The new test reproduces a real saved/read-back joint target without an owner; it does not claim a two-process world restart.

Only UUID references and cooldowns are stored in parent turret NBT. Reading them never recreates a missing module/joint or grants an unspawned clone authority. Actual anchor damage removes the joint. The child keeps exact pose, linear velocity and angular momentum at separation, enables world gravity and stops receiving parent fire. On the authored UFO this cut can also detach the existing 60-cell roof cap; this is real topology, not fabricated debris.

## Contacts and numerical boundaries

`BodyJointLink.collideConnected=false` disables only the bearing pair's hull/hull contact. Old links and absent NBT fields default totrue; registry edits and material migration preserve the flag. The turret retains its own compound collider for actors, terrain and unrelated bodies. The GameTest checks the actual contact query as well as persistence/default compatibility.

Native separation originally exhausted 96 contact events, froze the three physical bodies and eventually lost piloting. Two saved actual states reproduce the problem independently. Resting contact skin is now separate from physical TOI detection: a separated approaching pair cannot become an instantaneous impact merely because it is within the resting skin. A recurring already-resolved zero-time contact receives a bounded 0.1 mm separation. First impacts retain their exact TOI. COM correction transfers the equal orbital contribution into spin to retain world angular momentum. Solver/event/CCD limits were not raised; fragments are not excluded from collision.

Both saved fixtures run 12 physical steps, retaining movement and strict `1e-7` linear / `1e-6` angular phase invariants. The first expanded full run retained 314 passes and failed this new angular assertion at a multi-million-block test-grid offset: measured `1.2217917910662156e-5`. The native fixture now uses its own near-origin loaded columns, retaining the strict tolerances and all continuity checks. **An absolute 1e-6 angular-momentum guarantee at multi-million coordinates is not certified**; the original failure/XML remains evidence. This fixture correction is not a claim that large-world floating-point precision has been redesigned.
