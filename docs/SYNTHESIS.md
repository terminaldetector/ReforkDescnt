# Синтез, не солянка

Ключевые слова: **синтез** и **единый визуальный язык**.

Если просто сложить идеи из разных игр — получится эклектика. Если у всех элементов одна логика, они работают как **один мир**.

| Источник | Что берём | Как это же в DRMD |
|----------|-----------|-------------------|
| **Oblivion** | Заброшенная автоматизированная Земля, мегаструктуры | Кольцо, архонты (эндермены), рыскатели, гигареактор |
| **Strafe** (Doom Engine) | Грязная индустриальная эстетика, **техно-средневековье**: реакторы чинят сотни лет вместо замены | Биом `iron_guild` / анклавы, ржавые комплексы, гильдии |
| **Minecraft** | Процедурность, строительство, свобода | Плиты, колонна, крафт, исследование |
| **Descent** | 6DoF и 3D-навигация | Полёт Pyro, объёмные данжи |

Игрок не должен читать «набор отсылок». Он исследует **остатки одной цивилизации**, пережившей свою эпоху.

Цель шире, чем «добавить предметы»: изменить **ощущение** от мира — *переделать Minecraft под себя*, как крупные моды, создававшие жанр внутри игры.

Держать в фокусе: треножники, кольцо, скафандр, архонты и техно-средневековые биомы выглядят как части **одной** системы. См. также [`WORLD_PHILOSOPHY.md`](WORLD_PHILOSOPHY.md).

## Анклавы, касты, диалоги, квесты

После катастрофы остались небольшие анклавы людей — не ванильные деревни. Каждый генерируется параметрами:

| Параметр | Примеры |
|----------|---------|
| Происхождение | военные, инженеры, шахтёры, культисты, мусорщики |
| Отношение к автоматам | ненавидят / используют / поклоняются |
| Уровень технологий | 0…3 |
| Ресурсы | железо, топливо, схемы, еда… |
| Соседи | вражда / нейтрал / союз с другими плитами |

Из этого рождаются **процедурные диалоги** (атмосфера + информация без кат-сцен) и **квесты** из состояния мира:

- отбить налёт треножников;
- восстановить старый реактор;
- исследовать заброшенную шахту;
- найти пропавший дрон;
- добыть компонент скафандра.

Фракции помнят действия игрока (`FactionMemory`): инженеры модернизируют скафандр; технокульт открывает древние объекты, но ждёт, что управляющие системы не будут разрушены.

Код: `com.terminaldetector.drmd.world.enclave.*`, биом `drmd:iron_guild`.
